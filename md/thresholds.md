# 判断のしきい値 / Decision thresholds

部長AIは、すべての成果物と判断を次の4つのどれかに振り分ける。

| 区分 | 意味 | 例 |
|---|---|---|
| ACCEPT | 部長が単独で受け入れる | 基準を満たし、元に戻せる作業 |
| WARN | 受け入れるが、記録に注意を残す | 基準は満たすが、前例が少ない |
| ESCALATE | 秘書を通じて人間に上げる | 支払い・公開・削除・他者への約束など、元に戻せない行為 |
| BLOCK | 受け入れない | 基準違反、個人情報の漏えい、秘密情報の混入 |
