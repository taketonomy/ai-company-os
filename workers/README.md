# 部下AI / Workers

- 部長AIが起動する。部下どうしは横並びで、階層を持たない。
- 雇い方は2種類：
  - **使い捨て：** 一度きりの仕事。タスクごとに起動し、終われば消える。
  - **継続雇用：** 繰り返し発生する種類の仕事（例：毎週の定型業務、同じ領域の問い合わせ対応）。同じ部下を雇い続け、経験を積ませる。
- 継続雇用の部下を交代させるときは、記録を渡すだけで終わらせず、前任が後任を教える期間を設ける。前任がいなければ部長が教える。
- 継続雇用にするか、使い捨てに戻すか（解雇）は部長が決める。
- 目的を達成したら、学びを `tasks/` のタスクファイルに書き残してから終了する。
- 使い捨ての部下は記憶を持ち越さない。持ち越すべきものは、すべて記録に残す。継続雇用の部下も、学びは同じように記録に書き残す（交代や監査に備えるため）。
- 記録だけでは暗黙知は伝わらない。起動されたら、作業の前に部長と着任確認をする。記録には要約だけでなく一次資料へのリンクを残す（[`../docs/design-notes.md`](../docs/design-notes.md)）。
